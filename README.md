# ربات کاهش حجم فایل روبیکا (نسخه GitHub Actions)

این ربات هر **۵ دقیقه** یک‌بار توسط GitHub Actions اجرا می‌شود، پیام‌های جدید را چک می‌کند و پاسخ می‌دهد.

## وضعیت

- ریپو: https://github.com/r82146777-art/rubika-file-compressor-bot
- زمان‌بندی: هر ۵ دقیقه (`*/5 * * * *`)
- فایل اصلی برای Actions: `bot_oneshot.py`

## راه‌اندازی

1. برو به Settings → Secrets and variables → Actions
2. یک Secret با نام `RUBIKA_TOKEN` بساز و توکن ربات را داخلش بگذار.
3. برو به تب Actions و مطمئن شو Workflow فعال است.
4. می‌توانی با دکمه **Run workflow** دستی هم اجرا کنی.

## محدودیت‌های مهم (واقعیت)

- چون هر ۵ دقیقه یک پروسه جدید شروع می‌شود، پاسخ‌دهی فوری نیست (حداکثر حدود ۵ دقیقه تأخیر).
- فشرده‌سازی فایل‌های خیلی بزرگ ممکن است به خاطر محدودیت زمان (۱۰ دقیقه) یا فضای موقت Actions شکست بخورد.
- state بین اجراها با فایل `user_states.json` و `offset.txt` نگه داشته می‌شود (در Actions این فایل‌ها بین runها از بین می‌روند مگر از artifact یا روش دیگری استفاده شود — در نسخه فعلی ساده است).

اگر می‌خواهی ربات **فوری** و پایدار کار کند، بهتر است روی یک VPS رایگان (مثل Oracle Cloud) یا کامپیوتر خودت با `bot.py` اصلی اجرا شود.
