# ربات کاهش حجم فایل روبیکا

ربات برای کاهش حجم ویدیو، صوت، تصویر، PDF و فایل‌های دیگر در پیام‌رسان روبیکا.

## نصب و اجرا

```bash
pip install -r requirements.txt
# نیاز به ffmpeg:
sudo apt install ffmpeg -y
# اختیاری برای PDF:
sudo apt install ghostscript -y

python bot.py
```

## نحوه استفاده

1. ربات را در روبیکا استارت کنید.
2. فایل مورد نظر را ارسال کنید.
3. سطح فشرده‌سازی را انتخاب کنید.
4. فایل کم‌حجم شده را دریافت کنید.

**توجه:** این ربات باید روی یک سرور یا سیستم همیشه روشن اجرا شود.
